- **Information**
    - 10개 주요 암호화폐 거래소의 실시간 코인 가격 및 오더북 데이터를 수집하여 평균 가격을 계산하고, 지역별 및 거래소별 가격 추이를 분석하는 시스템을 단독으로 설계하고 구현했습니다.
    - 이를 통해 어느 지역과 거래소에서 거래하는 것이 가장 이익이 되는지 파악하고, 거래소별 가격 변동을 대시보드로 시각화하여 유의미한 인사이트를 도출하는 것을 목표로 했습니다.
- **Contribution**
    
    **Kafka 기반 실시간 코인 데이터 수집 구조 개선**
    
    - 기존 구조는 거래소별 토픽 방식으로 운영되어 **총 18개 이상의 토픽과 불균형한 파티션 분배로 인한 메시지 지연 및 소비 처리 지연 문제**가 발생함. 거래소 추가 시마다 신규 토픽 및 파티션 생성을 요구하여 **운영 복잡도와 유지보수 비용 증가**.
    - **토픽을 지역 단위로 통합하고, 거래소를 파티션 단위로 분리하는 구조로 재설계**. **Kafka** **Custom Partitioner 직접 구현**을 통해 거래소 기준 메시지 자동 라우팅을 실현하여 운영 효율성 극대화.
    - 구조 개선 결과,
        - **토픽 수 18개 → 6개로 66% 감소**,
        - **신규 거래소 추가 시 파티션 확장만으로 대응 가능**,
        - **데이터 처리 지연률 30% 이상 감소**,
        - **시스템 메시지 처리량 1.8배 향상**,
        - **평균 장애 복구 시간 15분 → 5분으로 66% 단축**.
    - 또한, **수동 커밋 전략 및 파티션 단위 모니터링 체계 도입**으로 문제 거래소 실시간 식별 가능해짐.
    - 결과적으로 **운영 안정성 향상**, **장애 대응 속도 개선**, **서비스 확장성 확보**에 기여.
